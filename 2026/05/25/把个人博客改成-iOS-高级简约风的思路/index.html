把个人博客改成 iOS 高级简约风，我主要做了什么

2026-05-25 建站日志

这次我给博客做样式升级，核心目标不是“花哨”，而是让整个页面看起来更轻、更干净、更有呼吸感。

这类风格的关键不是毛玻璃本身

真正让页面显得高级的，通常是这些细节：

  • 留白足够克制
  • 圆角和阴影统一
  • 色彩不多，但有层次
  • 视觉重点非常明确

所以这次不是单纯加一个 backdrop-filter 就结束，而是把导航、封面、卡片、搜索页、个人主页都统一成同一套语言。

我最在意的三个体验点

1. 首页第一屏要有记忆点

我把标题页做成了左侧介绍、右侧播放器的结构。这样第一眼不只是“博客列表”，而是更像一个个人展示页。

2. 头像入口要有意义

右上角头像不只是装饰，而是通往个人主页的主入口。点进去可以看到我的方向、基本信息和社交链接。

3. 搜索必须真正可用

很多个人博客有搜索入口，但体验很弱。这次我把站内搜索接起来后，希望它能成为真正的内容检索工具，而不是一个摆设。

后续还会继续补什么

接下来我还想继续优化：

  • 文章封面图系统
  • 项目展示页面
  • 更完整的 Java / Agent 专栏内容

博客对我来说，不只是一个发布页，更像一个会持续成长的个人作品。
